# 项目上下文

## 开发环境

开发环境的 MySQL 首次初始化空数据目录时，会执行 `docker/dev/init/mysql-init.sql`，将基础表和数据导入 `ruoyi_rust_dev`。使用已初始化的数据目录启动时会跳过该脚本。

移动端 H5 使用 uni-app Vue 3 和 Vite。在 `front-app` 执行 `npm ci` 安装依赖，再执行 `npm run dev:h5` 启动，访问 `http://localhost:9090`。端口由 `front-app/manifest.json` 配置。npm 脚本显式加载 `vite.h5.config.mjs`，HBuilderX 继续使用自带的编译配置。
